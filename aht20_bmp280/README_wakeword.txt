СЛОВО-АКТИВАТОР «ALEXA» — КАК ПРОШИТЬ МОДЕЛЬ
=============================================

Нейросеть, которая слышит «Alexa», лежит не в прошивке, а в отдельном разделе памяти "model".
Её нужно прошить ОДИН РАЗ через USB. Дальше обычные прошивки (кабелем, через сайт или по Wi-Fi)
её не трогают.

Файлы:
  partitions.csv      — разметка памяти с разделом model (Arduino IDE берёт её из папки скетча сама)
  srmodels_alexa.bin  — модель wn9_alexa из esp-sr 2.1.5 (github.com/espressif/esp-sr), упакованная
                        в формат esp-sr


Шаг 1. Прошить скетч КАБЕЛЕМ (не через сайт и не по Wi-Fi!)
-----------------------------------------------------------
Новая разметка памяти записывается только при прошивке по USB.
В меню Partition Scheme оставь "16M Flash (3MB APP/9.9MB FATFS)". НЕ выбирай "ESP SR 16M",
иначе Arduino IDE попробует прошить свою модель и выдаст ошибку.
Настройки, ключ Groq и привязка к «Дому» сохранятся.


Шаг 2. Прошить модель
---------------------
1. Закрой Serial Monitor (он занимает порт).
2. Посмотри номер порта в Arduino IDE: Инструменты -> Порт (например COM5).
3. Открой командную строку в папке скетча и выполни (COM5 замени на свой порт):

   "%LOCALAPPDATA%\Arduino15\packages\esp32\tools\esptool_py\5.1.0\esptool.exe" --chip esp32s3 --port COM5 --baud 921600 write-flash 0xD10000 srmodels_alexa.bin

Если esptool не может подключиться: зажми BOOT, нажми и отпусти RESET (или переподключи USB),
отпусти BOOT и повтори команду. После прошивки нажми RESET.


Шаг 3. Проверить
----------------
В Serial Monitor при запуске должно быть:
   [wake] модель wn9_alexa, кусок ... отсчётов, эхоподавление включено
На странице в блоке «Ассистент»: «Слушать слово „Alexa“ · работает (wn9_alexa)».

Скажи «Alexa» — светодиод загорится белым, дальше задавай вопрос, как после кнопки BOOT.
